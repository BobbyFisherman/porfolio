VISION VOICE

Real-Time ASL Translation Glasses

A wearable accessibility system that translates American Sign Language into spoken and visual communication in real time — combining custom-designed smart glasses, computer vision, machine learning, and embedded hardware.

GH Source Code HW Hardware + ML Pi Raspberry Pi 5
01

Project Overview

◎
Problem
Over 500,000 people in the US use ASL as their primary language, yet most hearing individuals cannot understand sign language — creating a persistent communication barrier in daily life.
⚡
Solution
Vision Voice is a pair of smart glasses that watches a signer's hands, recognizes ASL gestures in real time, and instantly outputs the translation as both spoken audio and projected text — no phone or screen needed.
▲
Goal
Create an affordable, self-contained wearable that makes ASL communication accessible to everyone — bridging the gap between Deaf and hearing communities seamlessly.

01 Custom Glasses Frame

Designed in Onshape and 3D printed to house a micro-camera module, wireless transmitter, temple-mounted speakers, and a lens-mounted micro-display — all integrated into a wearable form factor.

3D Printed Onshape CAD Custom Housing
02 Computer Vision Pipeline

A micro-camera captures the signer's hands and feeds frames to MediaPipe for real-time 3D hand landmark extraction — producing 21 landmark points per hand at high frame rates.

MediaPipe 21 Landmarks Real-Time
03 ML Classification Engine

A trained machine learning model running on the Raspberry Pi 5 (8GB) receives landmark data and classifies ASL signs, mapping each recognized gesture to its corresponding English word in real time.

Raspberry Pi 5 8GB RAM Python
04 Dual Output System

Translated words are delivered through two channels simultaneously — audio playback via speakers built into the glasses' temples, and text projection onto a micro-display mounted on the inner lens.

Temple Speakers Lens Display Dual Channel

Hand Landmark Detection
Integrated micro-camera with MediaPipe to capture and extract real-time 3D hand landmarks (21 points per hand) from live video feed.

ASL Classification Model
Built and trained a machine learning model on Raspberry Pi 5 (8GB) to classify ASL signs from landmark data and map gestures to English words.

Wireless Data Relay
Integrated wireless micro-transmitter to relay processed data between the glasses and pocket processing unit in real time with minimal latency.
Completed

Engineered audio output through temple-mounted speakers and text projection onto the lens micro-display — both channels working simultaneously from classified output.
